Đang tải soundfont Nokia…

Chọn một hoặc nhiều file. File của game không cần đuôi .mmf (ví dụ BGM_07_MMF): app nhận diện theo nội dung (chữ MMMD ở đầu file).

Đổi soundfont / chi tiết

Mặc định dùng Nokia.sf2 đi kèm trang. Có thể chọn file .sf2 khác (chỉ dùng trong lần mở này):

Bộ chuyển MMF → MIDI là bản JavaScript của hl4.core.Smaf (project HL4 cũ), đã so khớp từng byte với bản Java trên 125 file MMF của game. File chỉ có PCM (ADPCM) được giải mã ra WAV như bản gốc. Bộ phát soundfont là bản đơn giản: không có reverb, chorus, filter, LFO.

Về app

MMF → MIDI dùng bản JavaScript của bộ chuyển hl4.core.Smaf (project HL4 cũ), đã so khớp từng byte với bản Java trên 125 file MMF. File MMF chỉ có PCM (ADPCM) được giải mã ra WAV. MIDI được dựng bằng bộ phát soundfont đơn giản (không reverb, chorus, filter, LFO). File của game không có đuôi (ví dụ BGM_07_MMF) được nhận diện theo nội dung.

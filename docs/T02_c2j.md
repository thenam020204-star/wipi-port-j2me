# T0.2 — Bộ dịch bán tự động pseudo-C → Java (`tools/c2j.py`)

Người dùng duyệt 2026-10-17. Bản nháp sinh ra **vẫn phải** qua kiểm từng hàm (T0.1) trước khi tính là port xong.

## Cách dùng
```
python3 tools/c2j.py TÊN [TÊN..]          # method Java (nháp) ra stdout; dòng "// C2J-CHECK <lý do>" = chỗ phải đọc disassembly
python3 tools/c2j.py --stats TÊN..        # chỉ đếm C2J-CHECK
python3 tools/c2j_eval.py <ref calls> <spec> TÊN,.. hl4.test.GameTraceTest <trace> <end> 500 <keys..>   # thay method tay bằng nháp, kiểm T0.1
```
Hàm đã có bản Java → nháp giữ đúng chữ ký Java (thay thế tại chỗ). `c2j_eval.py` dùng bản đã sửa ở `work/c2j/fixed/TÊN.java` nếu có.

## Bộ dịch làm gì
- Phân tích pseudo-C **thô** của Ghidra bằng `pycparser` (giữ được độ rộng phép ghi `*(T *)(p + off) = v`).
- Truy cập bộ nhớ → `Bytes.s8/u8/s16/u16/s32(p.m, off)` / `Bytes.w8/w16/w32`; global `_game/_event/_map/...` → `G.*`; `_g._O_N_` = N byte ở offset O.
- Biến cục bộ là `int`, gán vào biến char/byte/short/ushort được cắt như C; toán hạng `uint` dùng `>>>` và so không dấu; **phép cộng/trừ có toán hạng byte/ushort/uint so không dấu** (quy ước kiểu của Ghidra; có C2J-CHECK).
- Lời gọi → method Java theo javadoc (`/** TÊN ...`), dự phòng theo tên (`PREFIX_ten` → method `ten` của lớp cùng tiền tố, có C2J-CHECK); hàm gốc trả object cố định (`MP_getHero`) → `Pool.hero`; hàm chưa port mà thân chỉ là `return <biểu thức>` hoặc vài phép ghi theo tham số → inline; còn lại → `throw ...: later`.
- Ghidra bỏ đối số khi thanh ghi giữ nguyên tham số của hàm gọi → điền tham số cùng vị trí (C2J-CHECK).
- `(v = E, C(v))` trong điều kiện → `C` với lần đọc đầu của v thay bằng `(v = E)`; `goto` tới nhãn phía sau trong khối bao ngoài → khối có nhãn Java `L: { ... break L; ... }`.
- Biến Ghidra dùng chung cho object và số (tái dùng thanh ghi) → tách `v` (int) / `v_o` (Obj); con trỏ struct tiến theo hằng (`p = p + 8`) → biến offset `p_off`.
- Đánh dấu C2J-CHECK: vòng lặp, goto còn lại, phẩy, số đối số lệch, con trỏ số học, mảng/bảng trên stack (`memcpy` của `C.x.y`), lấy địa chỉ (tham số ra), chia không dấu, global lạ, so không dấu suy từ kiểu.

## Giới hạn / việc tiếp
- Hàm có bảng hằng chép lên stack (`memcpy` từ `C.x.y`) và struct ra: chưa tự động (đề xuất: tra bảng rodata đã có trong Java theo địa chỉ `C.x.y`).
- Chỉ mục dựa vào javadoc; method Java không ghi tên gốc chỉ được tìm theo tên gần đúng. Ghi đủ `TÊN @0x...` khi port giúp bộ dịch.
- Số đo tốc độ thật (hàm/giờ khi agent dùng c2j) sẽ có ở module D1/D2 tiếp theo (PLAN_NEXT §7).
